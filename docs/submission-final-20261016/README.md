# BF16 与官方 INT8 最终候选材料

本目录分别准备 [BF16 结果卡](bf16.md)、[INT8 结果卡](int8.md)和共同的[环境声明](env_declare.yaml)。关键 SLA 档位的三轮复测与逐请求审计已经完成，详见上级目录 `FINAL-VERIFICATION-20261016.md`；文件状态与尚未完成项不隐去。

本批次覆盖 BF16 4K C16 / 64K C2、INT8 4K C16/C28 / 64K C2，另因 C28 单轮超时延门槛而补测 C27。两精度使用各自已完成 GSM8K 审计的最终服务配置；不再启动其他精度数据集。
